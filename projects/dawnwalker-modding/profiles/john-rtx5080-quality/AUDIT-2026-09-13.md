# RTX 5080 Quality + Smoothness Profile — audit (2026-09-13)

## Scope

Read-only audit of the installed `~JohnRTX5080Quality_P.pak` on current Steam
build `25232147`. No game save, executable, graphics DLL, or base archive was
modified during the audit.

## Package integrity: passed

- `repak info` reads the installed archive as a valid Unreal Pak V3 archive.
- It contains exactly two expected files:
  - `Engine/Config/Windows/WindowsEngine.ini`
  - `Dawnwalker/John RTX 5080 Profile.txt`
- There are no executables, DLLs, assets, or unrelated game packages inside.
- The configuration has 52 settings with no duplicate setting keys.

## Configuration review: passed

The profile does not force resolution, DLSS mode, frame generation, quality
preset, Lumen, shadows, foliage, or ray tracing. Its purpose is limited to:

- texture and Nanite streaming budgets;
- shader and PSO caching;
- asynchronous loading and decompression;
- multi-threaded rendering/loading settings;
- D3D12 residency management and input smoothing.

The review found no resolution-forcing command, low worker-thread cap, GPU crash
diagnostic disable, or VRS image-quality override. That is intentional: the
profile avoids the higher-risk lines found in generic launch-day Engine.ini
packs.

## Rebuild comparison: passed

The profile was rebuilt from its saved source and independently checked. The
archive-level hashes differ because package text records a trailing newline, but
the extracted `WindowsEngine.ini` and profile readme match the installed files
in all functional content. The only differences are terminal blank lines.

## Limits of this audit

This confirms the package structure and configuration content. It does **not**
claim a measured FPS improvement or prove every Unreal console variable remains
accepted on build `25232147`; that requires a controlled in-game benchmark.

## Decision

Keep this single profile installed. Do not stack full Nexus Engine.ini optimizer
packages on top of it. The next useful work is a repeatable in-game benchmark
at 4K Ultra with DLSS Balanced and 2x frame generation, recording average FPS,
1% lows, and frametimes before changing any value.
