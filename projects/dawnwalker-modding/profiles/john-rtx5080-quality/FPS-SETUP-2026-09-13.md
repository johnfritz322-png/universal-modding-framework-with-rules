# Dawnwalker RTX 5080 FPS setup — 2026-09-13

## Target machine and game build

- RTX 5080 (16 GB), driver `616.64`
- Ryzen 9 5900X (12 cores / 24 threads)
- 32 GB system RAM
- Alienware AW3225QF at 3840×2160 and 239 Hz
- Steam build `25232147`

## Active performance profile

`~JohnRTX5080Quality_P.pak` is already installed in the game's `~mods` folder.
It is the single Engine configuration profile for this machine. It focuses on
texture/Nanite streaming, shader caching, asset loading, and CPU scheduling
without forcing lower visual settings.

Do **not** install another full Engine.ini optimizer on top of it. Multiple
profiles change the same Unreal settings and the last one loaded wins, which
makes results impossible to diagnose.

## Research decision

The current Nexus options were reviewed against the installed profile:

- VynnGfx's *Optimized Tweaks TBOD* v1.11 is an older, generic 3 KB
  performance profile. Its author explicitly says not to combine similar
  optimization tweaks. The existing machine-specific profile was already built
  from the same safe categories but avoids its resolution-forcing line and
  untested visual changes.
- PicardMods' *Ultimate Graphics Quality and FPS Performance Boost* v2.1.1 is
  a quality-first Engine.ini package updated on 2026-09-12. It intentionally
  raises quality-related budgets and should not be stacked with the existing
  performance profile.
- *Uncapped Cutscenes and Menu FPS* v1.6 is not included. Its current Nexus
  page documents an experimental animation hook and reports a known bad
  interaction with performance troubleshooting. It does not improve normal
  gameplay frame rate.
- DLSS-replacement / OptiScaler packages are not included. They replace or add
  rendering DLLs and need a separate, scene-by-scene stability test; they are
  not a safe first change on an active modded installation.

## Applied setting

With the game closed, `GameUserSettings.ini` was backed up to:

```text
D:\Dawnwalker-Modding\performance-backups\GameUserSettings-before-fps-profile-2026-09-13.ini
```

Then only this existing game setting was changed:

```ini
bUseVSync=False
```

Resolution remains 3840×2160, fullscreen remains enabled, and the game's frame
rate limit remains uncapped. No save, executable, base archive, or graphics DLL
was changed.

## In-game settings to use

Use the game menu for these graphics choices; they are not forced by the mod:

1. Full Screen at 3840×2160.
2. Ultra preset.
3. NVIDIA DLSS, **Balanced**.
4. DLSS Frame Generation, **2x**.
5. Unlocked Frame Mode.
6. NVIDIA Reflex On + Boost, if exposed by the game.

If dense locations do not hold a base render rate near 60 FPS, use DLSS
Performance before lowering image-quality options. Frame generation improves
displayed FPS but cannot repair a weak base frame rate.

## First test

Launch the game and play one repeatable dense area for several minutes. Watch
for image artifacts, new stutter, or a crash. If any occur, restore the backed
up `GameUserSettings.ini`; the installed profile can remain in place.
