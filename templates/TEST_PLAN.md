# Test Plan

## Scope
- Feature/system under test:
- Game version/build:
- Mod version/commit:
- Test platform:
- Test profile/save:

## Entry criteria
- [ ] Project builds or packages successfully.
- [ ] Required dependencies are installed and version-checked.
- [ ] Known-good rollback exists.
- [ ] Test environment is reproducible.

## Core tests
- [ ] Mod installs/enables correctly.
- [ ] Game launches with mod enabled.
- [ ] Feature can be activated through intended player flow.
- [ ] Expected behavior occurs.
- [ ] Invalid/edge conditions behave safely.
- [ ] Reload/restart behavior is correct where relevant.
- [ ] Previously working systems still work.

## Persistence tests
- [ ] Fresh save/profile tested if relevant.
- [ ] Existing save/profile tested if relevant.
- [ ] Update from prior mod version tested if relevant.
- [ ] Uninstall/removal behavior documented if relevant.

## Compatibility tests
- [ ] Shared records/files/hooks identified.
- [ ] Common overlapping mods tested where practical.
- [ ] Load/priority behavior tested where relevant.
- [ ] Compatibility patch tested if present.

## Evidence
Record logs, screenshots, validator output, test save, reproduction steps, and exact build/commit.

## Result
Highest verified state:
Designed / Implemented / Compiles / Validates / Loads / Tested In-Game / Regression Tested / Compatibility Tested / Release Ready
